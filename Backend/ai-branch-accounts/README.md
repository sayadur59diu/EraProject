# AI Branch Accounts (Oracle, Spring Boot)

Endpoints to fetch account info, branch-wise summaries, and outstanding values from:
- `stfacmas` (Account Master)
- `stfetran` (Transactions)

Also includes an **AI Query** endpoint that converts natural language into **safe, read-only SQL** using Spring AI (OpenAI).

## Quick Start

1. **Java 21 + Maven** installed.
2. Set Oracle connection in `src/main/resources/application.yml`.
3. Export your OpenAI key (optional—only needed for the AI endpoint):
   ```bash
   export SPRING_AI_OPENAI_API_KEY=sk-...
   ```
4. Build & run:
   ```bash
   ./mvnw spring-boot:run
   # or
   mvn spring-boot:run
   ```
5. Swagger UI: <http://localhost:8080/swagger-ui.html>

## Schema Assumptions (Adjust as needed)

```sql
-- Account master
CREATE TABLE stfacmas (
  account_no       VARCHAR2(30) PRIMARY KEY,
  branch_code      VARCHAR2(10) NOT NULL,
  customer_name    VARCHAR2(200),
  product_code     VARCHAR2(50),
  open_date        DATE,
  status           VARCHAR2(20),
  current_balance  NUMBER(18,2) -- optional if you keep running balance
);

-- Transactions
CREATE TABLE stfetran (
  id            NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  account_no    VARCHAR2(30) NOT NULL,
  branch_code   VARCHAR2(10) NOT NULL,
  tran_date     DATE NOT NULL,
  tran_type     VARCHAR2(2) CHECK (tran_type IN ('CR','DR')) NOT NULL,
  amount        NUMBER(18,2) NOT NULL,
  narrative     VARCHAR2(4000),
  CONSTRAINT fk_stfetran_acc FOREIGN KEY (account_no) REFERENCES stfacmas(account_no)
);
CREATE INDEX ix_stfetran_acc_date ON stfetran(account_no, tran_date);
CREATE INDEX ix_stfetran_branch ON stfetran(branch_code);
```

If your schema differs, update the JPA entities and repository queries accordingly.

## Key Endpoints

- `GET /api/accounts/{accountNo}` — Account master info + latest balance (computed from transactions if no current_balance).
- `GET /api/branches/summary` — Branch-wise account counts and total balances.
- `GET /api/branches/{branchCode}/summary` — Summary for one branch.
- `GET /api/branches/outstanding` — Branch-wise outstanding (DR - CR).
- `GET /api/branches/{branchCode}/outstanding` — Outstanding for one branch.
- `POST /api/ai/query` — Natural language → safe SQL → result (read-only, limited rows).

## Notes on "Outstanding"
We calculate **outstanding** as: `sum(CASE WHEN tran_type = 'DR' THEN amount ELSE -amount END)` over `stfetran`.
Adjust logic to match your business definition.
